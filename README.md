## 📌 About the Project

> **"Turn threads into insights!"**  
This project brings **AI** into the world of **textile production**, helping businesses understand and optimize **costs** with accurate **selling price predictions** using a smart ML model.  

🎯 The goal?  
**Predict total selling price** based on:
- 🧶 Fabric type
- 🧵 Brand tier
- 🧷 Manufacturing cost  
- 💸 Margin, Tax, and more

---

## 🎨 Key Highlights

✅ AI-powered **XGBoost Regressor**  
✅ Cost-wise prediction & breakdown  
✅ 🧮 Train your own model with CSV  
✅ 🔌 Flask-powered backend  
✅ ⚙️ Plug-and-play structure for E-Commerce or ERP

---

## 🧠 Machine Learning Breakdown

**📍 Model Used:** `XGBoost Regressor`  
**🎯 Target:** `Selling Price`  

📥 **Inputs:**
- Fabric Type 👕
- Product Type 👗
- Size 📏
- Brand Tier 🏷️
- Fabric Cost 💰
- Manufacturing Cost 🏭
- Transport Cost 🚚
- Brand Value 🛍️
- Retailer Margin 🧾
- Tax (%) 🧮

📤 **Output:**
- Predicted Selling Price 🎯
